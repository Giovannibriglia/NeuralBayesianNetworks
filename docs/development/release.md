# Releases and documentation

## Releasing

1. Make sure `master` is green, including the nightly run (start it by hand
   if needed) and, when the change touches devices, the `gpu.yml` lane.
2. Tag and push:

   ```bash
   git checkout master && git pull
   git tag v0.23.0
   git push origin v0.23.0
   ```

3. `.github/workflows/publish.yml` builds the sdist and the wheel. The version
   comes from the tag through setuptools-scm (`tag_regex` in
   `pyproject.toml`); nothing is edited by hand. It checks the archives with
   `twine check --strict`, installs the wheel in a clean virtual environment
   and imports it, then uploads to PyPI with Trusted Publishing (OIDC; no token
   is stored in the repository).
4. Write the release notes on GitHub from the merged pull requests.

A manual run of `publish.yml` (Actions, "Run workflow") uploads to TestPyPI
instead, as a dry run. Between tags, installs from a checkout report a
development version such as `0.23.0.dev4+g1a2b3c4`; a clone without tags
reports the fallback `0.14.0.dev0+unknown`.

## The documentation site

The site is built by Sphinx from `docs/` with the PyData theme:

- `docs/conf.py` is the configuration;
- pages are MyST Markdown (`docs/**/*.md`);
- the notebooks in `examples/` are copied into `docs/examples/` at build time
  (git-ignored) and rendered from their stored outputs by myst-nb, never
  re-executed;
- `docs/api/` is generated by autosummary from the docstrings (napoleon reads
  the numpy style);
- the benchmark guides (`docs/BENCHMARKS.md`, ...) are also read on GitHub, so
  their links are written as repository paths; the build points links to
  files outside `docs/` at GitHub.

Read the Docs builds every push to `master` (the `latest` version at
<https://nbn.readthedocs.io>) from `.readthedocs.yaml`, with warnings as
errors; the `docs` job in `ci.yml` runs the same build on every pull request.
Build locally with:

```bash
uv run --extra docs sphinx-build -W --keep-going -b html docs docs/_build/html
uv run --extra docs sphinx-build -b linkcheck docs docs/_build/linkcheck   # check every link
```
